# OMEN ROLEPLAY

Arabic orange/black community website and Discord application portal for https://omen-rp2.github.io/Omen_Web/.

- Discord membership required for sign-in and applications.
- No interview: application, review-channel buttons, rejection reasons, role synchronization and private notifications.
- Owner settings, application status, and the existing FiveM queue bridge.

The live website uses the existing Bots_Turbo Railway service at `/omen`. See that repository's OMEN-PORTAL.md for live integration. The Node 24 server in this repository remains an optional standalone alternative: `npm ci && npm start`. See [SETUP.md](SETUP.md) for bot permissions, role/channel IDs, persistent storage and deployment. Never commit Discord secrets.
